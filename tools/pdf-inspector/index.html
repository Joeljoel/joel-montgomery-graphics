What do the PDF page boxes mean?
TrimBox
The intended finished size after trimming.
CropBox
The region visible in a PDF viewer, which may differ from the finished size.
BleedBox
The print-output region used to measure bleed relative to the TrimBox.
MediaBox
The full PDF page area, which can include printer marks.
ArtBox
An optional boundary around meaningful page artwork.

If the TrimBox or BleedBox isn't explicitly defined, the inspector marks bleed as unconfirmed. Page-box metadata does not guarantee the artwork actually reaches the bleed edge.

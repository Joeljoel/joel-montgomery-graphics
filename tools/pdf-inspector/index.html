What do the measurements mean?

TrimBox
The intended finished size after cutting.
CropBox
The region visible in a PDF viewer. It can differ from the finished size.
BleedBox
The region defined for bleed and production output. The extra margin is measured against TrimBox.
MediaBox
The full page area, potentially including printer's marks.

Some PDFs don't define trim or bleed boxes. In that case, the inspector shows the PDF's fallback dimensions and marks bleed as unconfirmed. A defined BleedBox does not prove that artwork actually reaches the edge.

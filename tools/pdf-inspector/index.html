What do the PDF page boxes mean?
TrimBox
The intended finished size after trimming.
CropBox
The region visible in a PDF viewer, which may differ from the finished size.
BleedBox
The print-output region used to measure bleed relative to the TrimBox.
MediaBox
The full PDF page area, which can include printer marks.
ArtBox
An optional boundary around meaningful page artwork.

If the TrimBox or BleedBox isn't explicitly defined, the inspector marks bleed as unconfirmed. Page-box metadata does not guarantee the artwork actually reaches the bleed edge.

What PDF Inspector measures

Drop one or more PDFs to see the finished page size and the bleed on each edge. The inspector reads the files locally in your browser.

Expand a page to compare its boxes. TrimBox describes the finished size. BleedBox describes the area reserved beyond the trim. If either box is missing, bleed is marked unconfirmed.

The measurements describe the file’s boundaries. Checking whether the artwork fills the bleed requires a visual inspection. Use Export CSV to save the measurements.
